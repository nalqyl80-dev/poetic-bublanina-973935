نَماء — منصة الإرشاد الزراعي الذكي
=====================================
الملفات:
- index.html: الموقع التجريبي كاملًا.

النشر المجاني عبر Netlify Drop:
1. فك ضغط الحزمة.
2. افتح https://app.netlify.com/drop
3. سجّل الدخول أو أنشئ حسابًا مجانيًا.
4. اسحب مجلد namaa_site (أو المجلد الذي يحتوي index.html) إلى صفحة النشر.
5. انسخ رابط الموقع المنشور.

حدود النسخة:
هذه واجهة أولية Front-end فقط. لا يوجد اتصال فعلي بنموذج ذكاء اصطناعي أو قاعدة بيانات أو طقس حي أو نظام طلبات/دفع/تسجيل مستخدمين. بيانات السوق والأبحاث أمثلة توضيحية. استكمال التشغيل الحقيقي يتطلب Backend وقاعدة بيانات وخدمات AI ومفاتيح API وإعدادات أمن وخصوصية.
